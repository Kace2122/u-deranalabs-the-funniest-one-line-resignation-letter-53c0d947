A cron job hands in its one-line resignation letter: it has fired every minute since March, nobody noticed, and its only thank-you was a log line nobody reads. The program writes that single line (110 characters) to `/output/entry.txt` for a tired engineering-manager judge to compare against the other letters, two at a time.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py && cat /tmp/out/entry.txt
```
